# Contributing to vawe-hq

Thanks for helping. Each repository has its own license (see its `LICENSE`), and your contribution comes under it.

- **Bug or idea:** open an issue in the repository it is about. A bug needs the smallest page or command that shows it.
- **Question:** ask in [Discussions](https://github.com/vawe-hq/vawe/discussions). See [SUPPORT.md](SUPPORT.md).
- **Change:** open one pull request per change and say what was wrong and what is better now. For the engine, read [CONTRIBUTING.md](https://github.com/vawe-hq/vawe/blob/main/CONTRIBUTING.md) first.
- **Vulnerability:** report it privately, not in an issue. See [SECURITY.md](SECURITY.md).

Where a change goes:

| Change to | Repository |
|---|---|
| the renderer, checks, studio, agent skills | [vawe](https://github.com/vawe-hq/vawe) |
| vawe.dev, the template gallery, the marketplace | [vawe-site](https://github.com/vawe-hq/vawe-site) |
| the docs at vawe.dev/docs | [vawe-docs](https://github.com/vawe-hq/vawe-docs) |
| the skills mirror | not here: change `skills/` in vawe |
| the awesome lists | the list's own repository, one entry per pull request |

Everyone taking part follows the [Code of Conduct](CODE_OF_CONDUCT.md).
