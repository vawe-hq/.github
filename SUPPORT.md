# Getting help

- Read the docs first: [vawe.dev/docs](https://vawe.dev/docs). `bin/vawe <verb> --help` explains each command.
- Run `bin/vawe doctor` when something will not install or render. It names the missing tool and the install line.
- Ask a question in [Discussions](https://github.com/vawe-hq/vawe/discussions).
- Report a bug or ask for a feature in [Issues](https://github.com/vawe-hq/vawe/issues).
